# Portfolio - Harshal Chaudhari

A modern, responsive portfolio website built with React.js, Vite, and Tailwind CSS. This portfolio showcases my work as a Python Full Stack Developer, detailing my experience, projects, and technical skills.

## Features

- **Modern Design**: Clean and responsive user interface using Tailwind CSS.
- **Project Showcase**: Detailed sections highlighting key projects and contributions.
- **Interactive Elements**: Dynamic components and smooth animations.
- **Resume Download**: Direct access to my latest professional resume.
- **Responsive Layout**: Optimized for both desktop and mobile devices.

## Tech Stack

- **Frontend**: React.js
- **Build Tool**: Vite
- **Styling**: Tailwind CSS, PostCSS
- **Deployment**: Configured for Netlify (netlify.toml included)

## Getting Started

### Prerequisites

Ensure you have Node.js installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Harshal3457/portfolio.git
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
